# Roadmap

This roadmap covers October 2026 to September 2027. It applies to every public repository of the `netresearch` organisation that does not carry its own `ROADMAP.md`. A repository-specific roadmap takes precedence over this one.

The roadmap is a maintenance commitment. It does not promise new features.

## Planned work

- **Security fixes** for the supported versions, within the times stated in [SECURITY.md](SECURITY.md).
- **Dependency updates** through Renovate, including updates for known vulnerabilities.
- **Platform compatibility** with the platform versions that are supported upstream during this period, for example the TYPO3 LTS releases and the PHP, Go and Node.js versions.
- **CI and supply-chain controls** from the shared workflows in this repository: tests, static analysis, dependency review and secret scanning.
- **Bug fixes** for reported defects in the latest release.

## Excluded work

- Support for platform versions whose upstream support has ended.
- Backports of new features to earlier major versions.
- Feature requests without a maintainer who takes them on. Such requests stay open as issues and can be implemented by contributors through pull requests.

## Changes to this roadmap

An organisation owner updates this file at least once a year. The next review is due in September 2027.
